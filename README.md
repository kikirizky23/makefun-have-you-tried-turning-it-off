One funny line from a hopeless tech support agent to a desperate customer: **"Let's turn it off and on again — I'll stay on the line while it restarts, for the part where nothing changes."** The gag twists the oldest fix in support: the agent opens with the classic, then volunteers to stay on the line for the restart — not to fix anything, just to keep the customer company through the part where nothing changes. The humour is the agent's cheerful uselessness; the customer is never the butt of it. The program writes this one line to `/output/entry.txt` and nothing else: one line, no extra words, no trailing newline.

## Run it

```sh
node main.ts
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), then reads the file back to make sure it holds exactly the line above.
